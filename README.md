# Browser Extension Security Audit 🧩

This project documents the process of auditing and cleaning up browser extensions to improve privacy, security, and performance.

---

## 🔍 Steps Performed

1. **Open Extension Manager**  
   - Accessed the browser’s **Extensions/Add-ons Manager**.

2. **Review Installed Extensions**  
   - Carefully reviewed all installed extensions.

3. **Check Permissions & Reviews**  
   - Verified each extension’s requested permissions.  
   - Checked user reviews and reputation online.

4. **Identify Unused or Suspicious Extensions**  
   - Flagged extensions that are outdated, unused, or had suspicious behavior.

5. **Remove Unnecessary Extensions**  
   - Uninstalled all suspicious or unneeded extensions.

6. **Restart Browser**  
   - Restarted the browser to apply changes and ensure stability.

7. **Check Performance**  
   - Observed improvements in browser speed and resource usage.

8. **Research Malicious Extensions**  
   - Researched how malicious extensions can:  
     - Track browsing data  
     - Inject ads or malware  
     - Steal personal information  
     - Slow down performance  

9. **Document Results**  
   - Listed all steps taken and extensions removed for transparency.



## 🧠 What I Learned

- How to identify risky browser extensions  
- Why reviewing permissions is critical  
- The impact of extensions on browser performance and privacy
